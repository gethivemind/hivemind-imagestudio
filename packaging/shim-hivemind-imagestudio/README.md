# hivemind-imagestudio has moved

The package is now **presidium-imagestudio** (the product was renamed Presidium Image Studio).

    pipx install presidium-imagestudio

This package exists only so existing installs keep upgrading: it depends on
`presidium-imagestudio[bg]` at the same version and contains nothing else. The `imagestudio`
command, the `imagestudio` Python module and your data folder are unchanged.

Project: https://github.com/presidiumdev/presidium-imagestudio
