## Description (≤ 10,000 chars)
Presidium Image Studio is a complete image studio that runs on your own computer. Nothing is uploaded, nothing is paid for, and there is no account.

WHAT IT DOES
• Create images from text with FLUX.1 schnell or Qwen-Image, with a live preview while they render.
• Edit by instruction ("the same scene at night, lit windows"), repaint only a painted mask, remove an object, or make variations.
• Sketch to image: draw a rough layout, describe it, let the model paint it.
• Upscale 4× or 16× with Real-ESRGAN. Remove backgrounds to a transparent PNG in seconds.
• Image to text: captions, alt text, tags, or "write the prompt that would make this", with a local vision model.
• Start from a template (product shot, social post with text, portrait, logo concept, wallpaper, thumbnail, poster, pattern) or let the prompt assistant turn a few plain words into a full prompt.
• Turn any picture into a look with one click: pencil sketch, watercolour, oil, anime, pixel art, claymation, film noir and more, or your own saved styles.
• Extend the canvas (outpainting) to a new shape, and fix faces so eyes and skin come out sharp.
• Organise work in projects, see every version of an image with what changed, search the gallery by meaning, batch tools on a selection, and export a project as a zip or a one-file web page.
• Use it from your phone on your own network: scan a QR code, and the full studio is on your phone, including the camera.
• An MCP server is built in, so AI agents and tools that speak MCP can use the studio too.

QUALITY IS A SETTING, NEVER A CONSEQUENCE
Most local tools quietly give you less when your machine is small. This one does not. The default is the best your machine can do, at full resolution and full steps; the machine decides how long it takes, not how good it looks. Before you commit, the studio tells you the expected time, measured on your own hardware. Faster presets exist and each states its trade-off plainly. If a setting will not fit in memory, the studio says so instead of pretending.

PERMISSIVE LICENCES ONLY
FLUX.1 schnell, Qwen-Image, Qwen-Image-Edit, Real-ESRGAN, IS-Net, U²-Net and Qwen2.5-VL: Apache-2.0, MIT or BSD throughout. Models with non-commercial or revenue-gated terms are excluded by policy. The studio itself is open source (Apache-2.0).

YOUR MACHINE, YOUR FILES
Models are downloaded only when you ask, pinned by SHA-256, and stored in your user profile. After setup the studio works offline. Every finished PNG carries its full recipe, so any image can be reproduced exactly. Bring your own models and LoRA files if you have them.

WHAT TO EXPECT
A 16 GB laptop without a discrete GPU renders a full-quality image in about an hour on the CPU build and roughly half that with the Vulkan build on integrated graphics; the studio measures this and shows it before each run. A desktop with a discrete GPU takes minutes. The first run downloads about 10 GB of model files with your consent.
